Reason and scope
================

requested that the SkyPC app source change be stashed while retaining a separate
legacy release entry point. This rollback does not alter prior signed artifacts,
the shared signing engine, credentials, or unrelated working-tree files.

Legacy release wrapper
======================

Mac-signing/release_skypc_v2.sh delegates to release_skypc.sh without
`--launch-agent-plist`. It rejects an input containing the compiled-in
`com.sub2s.skypc.login-agent.plist` marker and rejects callers that try to pass
`--launch-agent-plist`. This requires a real rebuild from the legacy source and
prevents accidental repackaging of an SMAppService binary as a legacy release.
