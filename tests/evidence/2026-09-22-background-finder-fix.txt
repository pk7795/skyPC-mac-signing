SkyPC DMG Finder background fix — 2026-09-22

Observed failure
================

The user opened the signed/notarized SkyPC 0.9.27 build 5 DMG and supplied a
screenshot showing the intended icon positions on Finder's plain dark
background. The mounted artifact contains background.tiff at 1800x702 pixels,
144 DPI, logical size 900x351 points. Its old icvp alias parses and resolves
through CoreFoundation, but Finder did not create pBBk/pBB0 background bookmark
records. The former automatic gate was therefore a false positive.

Root cause and decision
=======================

A writable copy of the build-5 image reproduced the failure: metadata written
directly with ds_store/mac_alias passed the helper's structural checks, while
Finder did not resolve the picture. A fresh positive-control image configured
by Finder wrote pBBk and displayed the background. The same fresh image using
only the direct writer did not write a bookmark.

Production now uses finder_layout.applescript to target the exact mounted POSIX
volume and front Finder window. Finder writes .DS_Store, its background alias
and bookmark. dmg_layout.py is read-only and rejects the image unless it finds
a non-empty pBBk/pBB0 record, matching alias volume/path/CNID, 900x351 logical
image and window size, and the expected icon positions. Failure occurs before
DMG signing and before Apple notarization.
